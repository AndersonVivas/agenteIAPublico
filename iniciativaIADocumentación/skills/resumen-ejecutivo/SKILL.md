# Resumen ejecutivo

- En la primera sección del documento escribe un resumen de máximo cinco líneas: qué hace el
  servicio, qué procesos de negocio soporta, quién lo usa y qué ocurre si deja de funcionar.
- Usa como fuente la evidencia de contexto de negocio (README y descripción del proyecto), las
  descripciones de la API y los nombres de las operaciones expuestas.
- No incluyas nombres de clases, librerías, rutas técnicas ni configuraciones en el resumen.
- Cierra el resumen con una lista breve "En este documento encontrarás:" que anticipe el
  contenido de las demás secciones.
