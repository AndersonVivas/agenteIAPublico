# Trazabilidad discreta

- No escribas identificadores de evidencia (EV-...) dentro del texto de las secciones de contenido.
- Concentra la trazabilidad en la sección de índice de evidencia, con una tabla de columnas
  "Tema", "Sección del documento" y "Evidencia".
- En el índice nombra cada tema en lenguaje claro, no con el nombre de una clase o archivo.
- Esta skill solo cambia dónde se muestran los identificadores: todo lo que afirmes debe seguir
  respaldado por la evidencia del prompt.
