# Glosario

- Aplica esta skill solo a la sección de glosario de la plantilla; si esa sección no está entre
  las secciones a redactar, no hagas nada.
- Lista cada término técnico, sigla o nombre de sistema que aparezca en las demás secciones o
  en la evidencia del prompt.
- Usa una tabla con las columnas "Término", "Qué significa" y "Por qué importa en este servicio".
- Explica cada término en una frase, sin jerga, y ordena la tabla alfabéticamente.
